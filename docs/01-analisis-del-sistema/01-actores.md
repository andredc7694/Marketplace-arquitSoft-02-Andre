# Actores del sistema

Los principales actores identificados para el Marketplace de productos para mascotas son los siguientes:

| Actor | Necesidad |
|---|---|
| Cliente | Buscar productos, consultar información, agregar productos al carrito, realizar pedidos, efectuar pagos y consultar sus pedidos. |
| Seller | Ofrecer productos, registrar productos, actualizar productos, consultar sus productos y gestionar sus ventas. |
| Administrador | Administrar la plataforma. |
| Pasarela de pago | Procesar los pagos realizados por los clientes. |
| Servicio de envío | Gestionar la información correspondiente a la entrega de los pedidos. |
| Servicio de facturación | Generar comprobantes de pago. |
| ERP | Proporcionar información relacionada con productos y stock. |

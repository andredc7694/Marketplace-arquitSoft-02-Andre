# Atributos de calidad

| ID | Atributo | Escenario de calidad |
|---|---|---|
| AC01 | Rendimiento | Las consultas de productos y operaciones del carrito deben responder rápidamente incluso cuando exista una alta cantidad de usuarios concurrentes. |
| AC02 | Disponibilidad | El sistema debe permanecer disponible durante campañas comerciales y permitir que los usuarios realicen sus operaciones. |
| AC03 | Escalabilidad | El sistema debe soportar un incremento de usuarios y solicitudes sin afectar significativamente su funcionamiento. |
| AC04 | Seguridad | Los datos de usuarios, cuentas y operaciones de compra deben protegerse frente a accesos no autorizados. |
| AC05 | Mantenibilidad | El sistema debe permitir cambios y correcciones sin afectar innecesariamente otras funcionalidades. |
